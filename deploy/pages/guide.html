Setup and integration

Use Cellar with your exports.

For the easiest setup, download the ready-to-run Java ZIP and follow the beginner manual. This guide also shows how developers can build Cellar Guard from source.

Build Cellar Guard from source.

To check a file on mobile or desktop, open the browser checker.

Want the ready-to-run Java app instead? Download the Guard release ZIP. For source development, install a JDK 21 or newer and use the commands below.

  1. Open the address printed in the terminal.
  2. Use Contracts to define what each import expects.
  3. Open Check and select an export to validate.
git clone https://github.com/suryandugy-glitch/Cellar-Studio.git
cd Cellar-Studio
sh run.sh

Local access defaults to 127.0.0.1:8080.
